一、PHP 基础语法

1.1 环境与运行

  • PHP 是服务器端脚本语言，跑在服务器（Apache/Nginx）上动态生成网页。
  • 浏览器只看到 PHP 输出的结果，看不到源码。
  • 本地环境：phpstudy（D:\phpstudy_pro），CLI 运行方式：
  • 网页运行：用 PHP 内置服务器 php -S 127.0.0.1:端口 -t 目录。

运行流程：浏览器发请求 → 服务器执行 PHP → PHP 算出结果 → 返回给浏览器。

1.2 文件结构与注释

  • PHP 代码必须包在 <?php ... ?> 里。
  • 没有 main()，脚本从上到下逐行执行。
  • 注释 // #（单行）、/* */（多行）不执行。

1.3 变量与类型

  • 变量**必须带 $**，不用声明类型（弱类型）。
  • 同一个变量可中途改类型：$x = 10; $x = "字符串";（CTF 漏洞常源于此）。
  • 未赋值变量 = NULL，输出不报错。
  • 类型自动转换："42" + 8 = 50（字符串自动当数字）。
  • 常量：define("X", 值) 或 const X = 值;。
  • 变量变量 $$：用变量的值当变量名。

1.4 运算符与比较（CTF 重点）

算术：+ - * / %（同 C）+ **（幂，C 没有）

字符串拼接：用 .（C 用 strcat）

复合赋值：+= -= *= /= .=（.= 拼接追加）

逻辑：&& || !　位运算：& | ^ ~ << >>

== vs ===（CTF 头号大坑）

运算符 比较方式 例子
== 松散：只比值，自动转类型 1 == "1" 真，"abc" == 0 真
=== 严格：值和类型都相等 1 === "1" 假

0e 魔法哈希：任何 0e 开头的字符串都被当 0，互相之间相等。

CTF 经典：md5($a) == md5($b) 且 $a != $b，找两个 md5 以 0e 开头的字符串即可通过。

数组绕过：strcmp($arr, "abc") 遇到数组返回 NULL，NULL == 0 为 true → 绕过校验。

2.1 危险函数清单

函数 作用 CTF 用途

exec() 执行命令返回最后一行 RCE

3.2 魔术方法

以 __ 开头，PHP 在特定时刻自动调用：

方法 触发时机 CTF 价值
__construct new 时 构造
__destruct 对象销毁时 常藏危险操作
__wakeup unserialize 时 反序列化必触发
__toString 当字符串用对象 常被串联
__call 调不存在的方法 高级利用
__invoke 当函数用对象 可触发执行
__get/__set 访问不存在属性 —

漏洞原理：代码把用户输入直接 unserialize，而某类魔术方法里有危险操作 → 攻击者控制属性值触发。

3.3 POP 链

POP = Property-Oriented Programming（面向属性编程），ROP 的属性版。

核心：攻击者不能直接调方法，只能控制属性；利用自动触发的魔术方法，把属性引导到危险函数。

3.4 __wakeup 绕过

CVE-2016-7124：序列化串里属性数 > 实际属性数时，PHP 跳过 __wakeup()。

用途：__wakeup 里若有拦截 / 校验，夸大属性数跳过它，危险操作就能执行。

四、CTF 高频坑速记

  1. "0e123" == 0 为真（0e 开头 = 0）；"abc" == 0 为真
  2. === 才查类型，== 只比值
  3. ?a[]=1 把参数变数组 → md5/strcmp/preg_match 失灵
  4. $_REQUEST 混吃三种来源，POST 优先 → 绕过单来源过滤
  5. eval/system/assert/include 是 RCE 与文件包含入口
  6. 类内读全局要 global，否则 NULL
  7. 反序列化漏洞 = 用户可控 unserialize + 危险魔术方法（__destruct/__wakeup）
  8. 过滤黑名单拦的是明文字符 → 用等价写法（tab / 通配符 / 拼接 / 换命令）绕过
